# 예울마루 MISO 작업 지침

인수인계는 항상 가볍게 유지한다. 누적 일지를 추가하지 않고 현재 구조·핵심 규칙·미해결 사항·다음 행동으로 기존 내용을 교체·압축한다. 해결 경과·중복 설명·낡은 수치를 제거하고 상세 패치·검증 증거는 별도 파일의 경로만 남긴다. 전체 작업 이력을 다음 담당자의 필수 읽기 목록으로 만들지 않는다.

새 UI와 기존 UI 변경은 `docs/UI-DESIGN-SYSTEM.md`, `docs/UI-SCREEN-MATRIX.md`를 먼저 읽고 정본 토큰·컴포넌트를 참조한다. `python3 tools/check_ui_contract.py` 실패를 우회하거나 기준선을 자동 갱신하지 않는다. 전체 전환/실화면 검증 상태는 matrix를 따른다. 개발본만 변경, 발행 금지.


## 모든 세션 시작
1. 이 파일과 `MISO-HANDOFF.md`, `ticketlink-collector/MEMBER-SYNC-NOTES.md`를 읽는다.
2. 인수인계의 완료/미완료/추정을 구분하고 현재 개발본 상태를 확인한다.
3. 개발 IDE를 새로고침하고 `<>` Code에서 관련 원문을 직접 읽는다. 드럼통 Database Workbench에서 실제 개발 DB 구조를 확인한다.
4. 최신 사용자 지시가 이 문서보다 우선한다. 승인된 범위의 개선은 반복 질문 없이 진행한다.

## 절대 제약
- **개발본만 작업. 발행 금지.** 개발 `ymdata_dev`, `ymmeta_dev`; 발행 `ymdata`, `ymmeta`와 혼동하지 않는다.
- 수집기는 내부망 PC에서 실행. 사용자 직접 로그인 방식 유지. 자동 로그인/시간별 수집으로 되돌리지 않는다.
- 비밀번호·쿠키·수집기 키를 채팅/문서/로그에 출력하지 않는다.
- 회원 원본은 마스킹 없이 GS 개발 DB에 보존한다. 연락처 정규화는 별도 필드. 화면 표시에서 마스킹한다.

## 조사와 설계
- 화면만 보고 로직을 추측하지 않는다. Code 편집기 원문을 직접 읽고 필요한 함수만 추출한다.
- 전체 대형 소스를 내부 모델이 반복 검색/분석하게 하지 않는다.
- DB 시트, 필드, 필수값, ID, 훅, 트랜잭션, 캐시, 기존 정규화 규칙을 확인한 후 설계한다.
- 프로그램 연결은 프로그램ID/사업코드 기준. 이름을 키로 삼지 않는다.
- 임의로 기존 회원/실적을 삭제하지 않는다. 원본과 기존 저장 계약을 보존한다.

## MISO 실행 방식
- 구현 판단은 외부 담당 에이전트가 수행한다. MISO에는 **완성된 Python 패치 파일 실행만** 지시한다.
- 패치에 정확한 변수명·경로·원문 앵커·사전조건·백업·문법검사·검증·실패 중단을 포함한다.
- 파일 첨부 후 `python3 <첨부파일>`만 실행, 성공 stdout/실패 stderr만 반환하도록 지시한다.
- 모호한 대명사, 자유 분석, 자동 수정, 추가 탐색을 시키지 않는다.
- 문법/검증 실패 시 앱 파일을 쓰지 않는다. 기존 파일은 백업한다.

## 편집기 입력 사고 예방
- 원문 읽기 후 코드 입력 포커스를 해제한다. 사용자 채팅 입력과 코드 입력이 섞일 수 있다.
- 의도하지 않은 글자가 보이면 저장하지 말고 저장 상태를 확인한다. 원문 재열기 후 비교한다.
- 2026-09-07 `ym-changelog-lib.js` 앞의 `ㅎ` 혼입은 미저장 상태였고 재열기로 정상 원문을 확인했다.

## 검증과 마무리
- 변경 후 MISO Refresh preview. 대량 DB 처리 중 무턱대고 재시작하지 않는다.
- 실제 API 응답·DB 건수·화면을 확인한다. 구현됨과 운영 검증됨을 구분한다.
- 대량 처리에서는 상태 조회를 쓰기 트랜잭션으로 만들지 말고, 훅/잠금/타임아웃 영향을 확인한다.
- 사용자가 요청한 화면 캡처는 파일로 보관하고 최종 답변에 이미지로 넣는다. 미완료 화면을 완료 화면으로 소개하지 않는다.
- 작업 후 `MISO-HANDOFF.md`와 관련 검증 기록을 갱신한다. 회원 원본/인증정보를 문서에 넣지 않는다.

- 대형 standalone.html 전체를 클립보드로 복사하면 도구가 종료될 수 있다. Code의 검색/관련 줄, 또는 개발 도구에서 필요한 함수 원문만 읽는다.
