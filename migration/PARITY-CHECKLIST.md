# MISO 화면·동작 동일성 기준

2026-09-11 사용자 요구: 현재 MISO에서 보이는 화면과 미세한 작동까지 이관본에서 동일하게 작동해야 한다. 기준 화면은 현재 개발 미리보기다. 8월 28일 발행본과 혼동하지 않는다.

원본 UI·계산·상태 전환을 유지하며, 동일 기능을 단순화한 대체 화면이나 성공 응답만 반환하는 임시 API를 완료품으로 취급하지 않는다. 동일 브라우저 크기·시간대·기준일·역할·데이터 조건에서 아래 항목을 양쪽에서 실행한다. 데이터 가명화에 따른 표시값 차이는 기능 보존과 구분해 기록한다.

## 이번 작업에서 확인한 것

- 원본 Code에서 수정 이력의 `SKIP_COLS["수정자"]` 값이 1임을 확인하고, 이관 과정에서 840으로 변한 로컬 상수를 복구했다. 해당 코드 설정을 사람 데이터로 가명화하지 않도록 변환기를 수정하고 회귀 검사를 추가했다.
- 공식 PocketBase 0.31.0을 사용한 별도 로컬 검증 DB에 가명 이전 데이터 70,014행을 가져왔다. 모든 행의 ID·컬럼·JSON 값 비교에서 불일치 0건. `local-db-verification.json` 참조.
- 마이그레이션 재실행 시 새 작업 없음, 로컬 서버 health 200, 미인증 개발/운영/인증상태 DB 조회는 403을 확인했다. 검증 서버는 종료했고 DB만 보존했다.
- 원본 전체 화면 파일의 읽기 응답은 200이었으나 큰 본문 처리 중 브라우저 도구가 종료됐다. 이번 세션에서 해당 파일의 새 해시를 얻었다고 기록하지 않는다.

원본 MISO의 플랫폼 인증, managed proxy/env, 컬렉션 원본 권한·인덱스, 수집기 키 및 AI 연결은 이전본에 아직 구성되지 않았다. 이 항목과 표의 미검증 항목이 남아 있으므로 현재 상태는 **이관 진행 중**이다.
