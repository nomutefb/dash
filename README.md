# 예울마루 대시보드 — MISO 소스 작업본

MISO의 현재 코드·정적 데이터와 운영/개발 DB를 직접 읽어 만든 Git 작업본입니다. 개인정보는 가짜 영문 정보로 치환했습니다. 실제 MISO 데이터와 발행본은 변경하지 않았습니다.

**웹 미리보기:** https://nomutefb.github.io/dash/

현재는 로그인 화면을 확인하는 정적 미리보기입니다. 로그인 서버와 DB가 연결된 실제 대시보드 서비스는 아닙니다. GitHub Pages는 `gh-pages` 브랜치의 루트에서 `public/`에 해당하는 파일만 게시합니다. `main`의 코드 수정만으로 이 브랜치가 자동 갱신되지는 않습니다.

- 현재 코드와 정적 자료: `api/`, `public/`, `src/`, `server-data/`, `tools/`
- DB: `data/database/*.jsonl` — 운영 18,643행, 개발 51,304행, 메타데이터 67행
- 스키마와 인증 테이블의 필드 구조: `data/database/schema.json`
- 원본 대조 결과와 제외 항목: `migration/export-report.json`
- 재검증: `node tools/export/verify-export.mjs`

회원 이름·아이디·전화·이메일·주소·생일과 예매번호 등을 일관된 가짜 값으로 바꿨습니다. 사업비, 판매금액·매수, 공연명과 공연 식별자, 관람 이력은 유지합니다. 예매 요약의 분할 파일은 변경된 회원키 끝자리에 맞춰 다시 만들었습니다. 같은 전화번호를 공유하던 원본 회원의 관계와 원래의 미매칭 기록도 유지합니다.

이 자료는 관람 이력이 남아 있는 개발용 가명 데이터입니다. 생일은 연도를 보존하고 월·일을 바꾸며, 원본 생일을 해석할 수 없던 값은 미상으로 유지합니다. 지역명은 가상의 영문 지역으로 바뀌므로 실지역 이름·지도·한국 주소 검색의 결과는 운영 환경과 다릅니다. 원본↔가짜 값 대응표는 저장하거나 커밋하지 않습니다.

## 실행 및 MISO 반영

원본은 MISO가 제공하는 런타임과 PocketBase API를 사용합니다. Git 연결만으로 MISO와 자동 동기화되지는 않습니다. 코드 변경을 검토한 후 필요한 코드 파일만 MISO Code 편집기에 반영하고 저장 응답과 실제 미리보기를 확인해야 합니다. 이 저장소의 가짜 DB를 실제 MISO DB에 덮어쓰면 안 됩니다.

`index.html`이 참조하는 `src/main.tsx`는 MISO 파일 조회에서 HTTP 403으로 접근이 제한되었습니다. 플랫폼 런타임이 만드는 파일, 실제 로그인 설정, 외부 서비스 인증도 포함되지 않으므로 독립 실행에 필요한 환경 구성은 별도 작업입니다. 로컬 독립 실행이나 운영 발행 완료를 의미하지 않습니다.

`.env`, 실제 인증 다이제스트·암호화키, 인증 테이블의 값, 런타임 상태와 이전 백업은 제외했습니다. 과거 설치 스크립트와 진단 자료의 인코딩된 사본 31개도 제외했고, 현재 사용되는 실제 코드와 데이터는 별도로 보존했습니다. `api/*-private.example.js`는 필요한 설정 형태만 보여 줍니다. 초기 인증을 우회하거나 약화하는 설정을 넣지 않았습니다. 원본의 사용되지 않는 과거 프로그램마스터 XLSX는 제외하고 최신 프로그램 데이터는 DB 및 기존 CSV/JSON 경로에 보존했습니다.

## 검증 범위

행 수, 회원↔예매 연결 수, 가짜 회원키 일관성, 예매 분할 위치, 금액·매수·공연 정보 등 보호 대상 값과 인증값 잔존 여부를 대조했습니다. 원격 자료는 API로 순차 읽었으며 하나의 DB 트랜잭션 스냅샷은 아닙니다. 검증 기록은 읽은 원본과 변환본 사이의 일관성을 증명하며 운영 시스템 전체의 동작을 보장하지 않습니다.

## 최종 감사 (2026-09-11)

일반 UI 문구의 잘못된 가명 치환을 복구하고, 일정·로그·설명문에 남아 있던 직원 이름을 기존 가명으로 맞췄습니다. 직원 이름과 겹치는 공개 공연명은 보존했습니다. CSS의 펫 이미지 경로도 실제 public 자산 위치에 맞췄습니다.

- 파일 해시 593개, DB 70,014행, 회원 30,477행, 예매 40,429행, 회원–예매 연결 23,063개, 샤드 22,630행 검증 통과.
- 변경된 구조화 자료와 내장 DB의 키·행 구조·수치 401,356개를 이전 로컬 커밋과 비교해 유지됨을 확인했습니다.
- 상세 결과: [최종 감사 보고서](migration/FINAL-AUDIT.md), [데이터 무결성](migration/audit-data-integrity.json), [실행 검증](migration/local-verification.json).
- 정적 참조 193개 중 184개 해결. 나머지 9개는 플랫폼 런타임·인증 설정·접근 제한된 `src/main.tsx` 관련 참조입니다.

이번 작업에서 MISO 원본은 변경하지 않았고, 최신 MISO를 다시 읽어 전체 동등성을 검증한 것은 아닙니다. 로그인 이후 기능, DB 재가져오기, 외부 연동과 PWA 설치 검증은 남아 있습니다. 자유서술형 개인정보 검사는 확인 가능한 직원 이름을 대상으로 했으며 모든 개인정보가 제거되었다는 보장은 아닙니다.
